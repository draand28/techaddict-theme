# Personal data exposure assessment, techaddict.ro, 2026-11-21

Technical summary for the controller. Not legal advice.

## What happened

An attacker had PHP code execution on the WordPress installation at
techaddict.ro through webshells present since at least March 2024. The
WordPress database credentials belonged to a MySQL account with global
privileges on the database server, so every database on 192.168.1.245 was
readable in principle.

## Data that was accessible

| System | Records | Data |
|---|---|---|
| WordPress `techaddict_wp` | 555,305 accounts | usernames, email addresses, hashed passwords, registration dates |
| phpBB `techaddict_phpbb` | 96 accounts (14 active, 82 inactive spam) | usernames, email addresses, bcrypt password hashes, last IP, 59 posts, 0 private messages |
| Other databases on the same server | unknown | terracactus, reforme, nubis, ade, tcn_panel, Minecraft auth, Nextcloud (separate MySQL user) |

WordPress content was minimal: 6 posts, 4 pages, 2 comments, no form-entry
table. The 553,900+ spam accounts registered between 2022 and 2026 inflate the
record count; only 164 accounts predate 2022 and a handful look like real
people.

No evidence of bulk export was found: no extra MySQL users, no added grants,
no malicious database objects, and no rogue WordPress administrator. MySQL
binary logging was enabled, so further forensic work is possible.

## Containment completed on 2026-11-21

- All webshells removed; WordPress core replaced and updated to 7.1.5; all
  plugins updated and checksum-verified.
- WordPress salts rotated, sessions invalidated, open registration disabled.
- Separate least-privilege database users created for WordPress and phpBB.
- Shared application database account rotated and reduced to per-database
  grants; the old password no longer works.
- Remote MySQL `root@%` locked; host-specific root accounts created with a new
  password stored in the secrets store.
- Forum sessions cleared; every active forum account must change its password
  at next login.
- `wp-file-manager` deactivated and quarantined.
- Web server headers and TLS, Cloudflare DNS, SPF, DMARC, CAA and MX records
  fixed.

## Risk assessment

Likely affected: email addresses and password hashes for forum users, and the
email addresses in the WordPress user table. Passwords were hashed (phpBB:
bcrypt; WordPress: phpass/bcrypt depending on age), but offline cracking is
possible for weak passwords.

Potential but unproven: other sites' databases and credentials on the same
MySQL server.

## Recommended notifications

- Assess under GDPR Article 33 whether the exposure is likely to result in a
  risk to rights and freedoms. Given email addresses and password hashes were
  reachable, a notification to the Romanian supervisory authority (ANSPC)
  within 72 hours of establishing the breach is likely required.
- Notify affected forum users and any real WordPress account holders directly,
  with a password reset instruction.
- Keep the incident record, the backup evidence, and the actions taken.
